# OLEDGuard

Mac mini に接続したモニターのうち、選んだモニターだけに、一定時間操作がなかったときに待ち受け(画像・動画)を重ねて表示する、メニューバー常駐アプリ。有機ELモニターの焼き付き防止用。

> 開発途中(ステップ1: 骨組みとメニューバー常駐)。完成時に README を書き直す。

## 必要なもの

- macOS 27 以降
- Xcode(またはコマンドラインツール)の Swift 6 以降

## ビルドと起動

```sh
make app   # build/OLEDGuard.app を作る(swift build + ad-hoc 署名)
make run   # 作ってから起動(起動中のものは終了させる)
```

## ステップ1の確認項目

1. `make run` でメニューバーに月のアイコンが出る。Dock にはアイコンが出ない。
2. メニューに「一時停止」「設定を開く…」「今すぐテスト表示」(まだ無効)「終了」がある。「一時停止」を押すと「再開」に変わる。
3. 「設定を開く…」で、接続中のモニターの名前・解像度・表示サイズ・位置・リフレッシュレート・UUID が表示される。
4. 設定画面を開いたまま、モニターを抜き差し/配置を変えると、一覧が更新される。
