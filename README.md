# OLEDGuard

Mac mini に接続したモニターのうち、選んだモニターだけに、一定時間操作がなかったときに待ち受け(画像・動画)を重ねて表示する、メニューバー常駐アプリ。有機ELモニターの焼き付き防止用。

> 開発途中(ステップ4: 動画再生)。完成時に README を書き直す。

## 必要なもの

- macOS 27 以降
- Xcode(またはコマンドラインツール)の Swift 6 以降

## ビルドと起動

```sh
make app   # build/OLEDGuard.app を作る(swift build + ad-hoc 署名)
make run   # 作ってから起動(起動中のものは終了させる)
```

## 設定の保存場所

`~/Library/Application Support/OLEDGuard/settings.json`(モニターの UUID ごとに保存。未接続のモニターの設定も残る)

## ステップ2の確認項目

1. 設定画面にモニターごとのセクションがあり、「待ち受けを使う」「待ち受けまでの時間(5〜60分の8択)」「ファイル」「表示方法」を変えられる。
2. 「選択…」で、画像(JPEG / PNG / HEIC / PDF)と動画(MP4 / MOV / M4V)だけが選べる。
3. アプリを終了して起動し直しても、設定が残っている。
4. 選んだファイルを Finder で別のフォルダへ移動してから設定画面に戻ると、「ファイルが見つかりません」と出る。
5. 「ログイン時に自動起動」を入れると、システム設定 > 一般 > ログイン項目 に OLEDGuard が出る。

## ステップ3の確認項目

1. 設定画面の各モニターにある「今すぐテスト表示」で、そのモニターだけが待ち受け(画像/PDF)で覆われる。他のモニターはそのまま操作できる。
2. 待ち受けをクリックすると閉じる。クリックは下のアプリに届かない。キー入力は元のアプリに届いたまま。
3. 「フィル」は画面全体を覆い、「フィット」は全体が見えて余白が黒になる。
4. メニューの「今すぐテスト表示」で、「待ち受けを使う」がオンのモニターすべてに表示される。
5. 全画面表示のアプリの上にも表示される。メニューバーや Dock も覆われる。
6. 待ち受けを出したまま画面ロック(control + command + Q)して戻ると、待ち受けは閉じている。

## ステップ4の確認項目

1. 動画(MP4 / MOV / M4V)を選んで「今すぐテスト表示」すると、音なしでループ再生される。
2. クリックで止まって閉じる。
3. アクティビティモニタで、待ち受けを閉じた後に OLEDGuard の CPU がほぼ 0% に戻る。
4. 再生できない動画(拡張子だけ .mp4 にしたテキストファイルなど)を選ぶと、待ち受けは出ずに設定画面に警告が出る。
